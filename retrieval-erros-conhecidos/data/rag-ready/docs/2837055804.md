# 1. GitHub

1.1 Falha na etapa Run Ant Build (ear) com erro: WEB-INF/lib does not exist

🧠 Resposta da BIA TECH – A etapa de build apresentou falha.

Olá! 👋

🔍 O que isso significa?
A etapa de build está falhando pois não consegue localizar a pasta WebContent/WEB-INF/lib, necessária para a montagem do artefato.

✅ O que você deve fazer:

- Acessar o arquivo pacote.properties no repositório da aplicação.
- Identificar a variável associada ao diretório WebContent/WEB-INF/lib.
- Comentar ou remover essa variável no build.xml.
- Executar um novo build após o ajuste.
🎯 Motivo:
Erro Build

👥 Time responsável:
Desenvolvimento

Olá! 👋

🔍 O que isso significa?

✅ O que você deve fazer:

- Informar quais jars do Starteam precisam ser migrados.
- Anexar aprovação do Gerente de Projeto.
- Seguir documentação:8.3. Correção dos jars embarcados - ENGENHARIA DE PLATAFORMA | Tribo

Erro Build

Desenvolvimento

1.3 Falha na etapa Publish artifact nexus com erro: Status 400 cannot be updated

🧠 Resposta da BIA TECH – A etapa de build apresentou falha.

Olá! 👋

🔍 O que isso significa?
O erro ocorre pois foi realizado rerun completo da pipeline, gerando conflito ao tentar publicar um artefato já existente no Nexus.

✅ O que você deve fazer:

- Não reutilizar o mesmo build com rerun completo.
- Iniciar um novo build/deploy.
- Garantir que a versão do artefato não esteja duplicada.
🎯 Motivo:
Erro Build

👥 Time responsável:
Desenvolvimento

1.4 Falha na etapa Run Ant Build com erro: javac invalid target release

🧠 Resposta da BIA TECH – A etapa de build apresentou falha.

Olá! 👋

🔍 O que isso significa?
Existe conflito entre as versões de Java configuradas no build.xml e no workflow/pipeline.

✅ O que você deve fazer:

- Validar a versão correta de Java utilizada pelo projeto.
- Ajustar a versão no build.xml.
- Garantir compatibilidade com a versão definida no pipeline.
- Executar novo build após ajuste.

Erro Build

👥 Time responsável:
Desenvolvimento

- Executar novo build após correção.
