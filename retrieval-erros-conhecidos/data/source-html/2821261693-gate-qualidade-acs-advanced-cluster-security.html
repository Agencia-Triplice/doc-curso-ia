Falha Scan Imagem Base

Durante o processo de scan realizado pelo ACS (Advanced Cluster Security), foi identificada uma falha. Essa falha está relacionada a vulnerabilidades presentes na imagem base declarada na instrução FROM do arquivo Dockerfile do repositório da aplicação.

🔍 O que isso significa?

A imagem base utilizada para construir a aplicação contém vulnerabilidades conhecidas que podem comprometer a integridade, segurança e conformidade do ambiente. Essas vulnerabilidades foram detectadas pelo mecanismo de análise do ACS.

✅ O que você deve fazer:

Como se trata de uma imagem base corporativa, a correção deve ser conduzida pelo time responsável pela gestão de imagens base, em conjunto com o time de segurança.

Ações recomendadas:

  • Validar se existe uma versão atualizada e segura da imagem base.
  • Atualizar o Dockerfile para utilizar a versão corrigida.
  • Reexecutar o scan após a atualização para garantir conformidade.

👥 Time responsável:

Falha Scan Imagem App

Durante o processo de análise (scan) realizado pelo ACS (Advanced Cluster Security), foi identificada uma vulnerabilidade na imagem da aplicação. Essa falha está relacionada a problemas encontrados após a execução do build da imagem, que inclui as instruções e configurações necessárias para a aplicação. Em outras palavras, a imagem gerada apresenta vulnerabilidades que precisam ser corrigidas para garantir a segurança do ambiente.

🔍 O que isso significa?

A imagem da aplicação contém vulnerabilidades conhecidas que podem comprometer a integridade, segurança e conformidade do ambiente. Essas vulnerabilidades foram detectadas pelo mecanismo de análise do ACS.

✅ O que você deve fazer:

Como se trata da imagem da aplicação, a correção deve ser conduzida pelo time de desenvolvimento, em conjunto com o time de Engenharia de Software.


Ações recomendadas:

  • Verificar o realtório do ACS.
  • Corrigir os apontamentos especificados no relatório.
  • Reexecutar o scan após a atualização para garantir conformidade.
