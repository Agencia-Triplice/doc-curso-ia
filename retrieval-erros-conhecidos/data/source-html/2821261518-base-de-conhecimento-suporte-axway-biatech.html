🚀 Erros de Publicação


1.1 🧩 UNSUPPORTED_API_SPECIFICATION

🧠 Resposta da BIA TECH – A especificação da API não está em um formato compatível com o API Gateway.
Olá! 👋

🔍 O que isso significa?
O arquivo .json ou .yaml enviado não segue a estrutura suportada (por exemplo, OpenAPI 2.0 ou 3.0).

✅ O que você deve fazer:
Ajuste a especificação da API para um formato aceito pelo Gateway (OpenAPI 3.x é o padrão recomendado).

🎯 Motivo:
A especificação da API não está em um formato compatível com o API Gateway.

👥 Time responsável:
Time de Desenvolvimento


1.2 🧩 MISSING_PARAMETER

🧠 Resposta da BIA TECH – Um ou mais parâmetros obrigatórios não foram informados.
Olá! 👋

🔍 O que isso significa?
O pipeline não conseguiu validar todos os campos necessários para publicar a API.

✅ O que você deve fazer:
Revise o arquivo de configuração (config.yaml, api.json) e adicione os parâmetros faltantes.

🎯 Motivo:
Um ou mais parâmetros obrigatórios não foram informados.

👥 Time responsável:
Time Axway / API STUDIO


1.3 🧩 INVALID_PARAMETER

🧠 Resposta da BIA TECH – Foi identificado um parâmetro com valor inválido.
Olá! 👋

🔍 O que isso significa?
O campo possui dados incorretos ou em formato inesperado.

✅ O que você deve fazer:
Corrija o valor do parâmetro de acordo com o schema esperado e valide antes de reexecutar o deploy.

🎯 Motivo:
Foi identificado um parâmetro com valor inválido.

👥 Time responsável:
Time Desenvolvimento


1.4 🧩 API_ALREADY_EXISTS

🧠 Resposta da BIA TECH – A API informada já existe no API Manager.
Olá! 👋

🔍 O que isso significa?
O Axway detectou uma API previamente registrada com o mesmo nome ou ID.

✅ O que você deve fazer:
Verifique se deseja atualizar a API existente. Em caso afirmativo, utilize a flag de atualização (updateOnly) ou altere o versionamento.

🎯 Motivo:
A API informada já existe no API Manager.

👥 Time responsável:
Time Axway
