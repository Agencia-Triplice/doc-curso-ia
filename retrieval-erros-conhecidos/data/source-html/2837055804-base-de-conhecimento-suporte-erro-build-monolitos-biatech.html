1.1 Falha na etapa Run Ant Build (ear) com erro: WEB-INF/lib does not exist

🧠 Resposta da BIA TECH – A etapa de build apresentou falha.

Olá! 👋

🔍 O que isso significa?
A etapa de build está falhando pois não consegue localizar a pasta WebContent/WEB-INF/lib, necessária para a montagem do artefato.

✅ O que você deve fazer:

  1. Acessar o arquivo pacote.properties no repositório da aplicação.
  2. Identificar a variável associada ao diretório WebContent/WEB-INF/lib.
  3. Comentar ou remover essa variável no build.xml.
  4. Executar um novo build após o ajuste.

🎯 Motivo:
Erro Build

👥 Time responsável:
Desenvolvimento

1.2 Falha na etapa Verifica Pendência de migração com erro: Necessário ajuste no repositório

🧠 Resposta da BIA TECH – A etapa de build apresentou falha.

Olá! 👋

🔍 O que isso significa?
Os jars internos utilizados no Starteam não foram migrados para o GitHub, causando falha na etapa de build.

✅ O que você deve fazer:

  1. Abrir chamado no BEX Access:
    https://devopsadmin.bradesco.com.br:8443/devopsadm/#/solicitacoes/suporte

  2. Selecionar suporte de Migração GitHub.

  3. Informar quais jars do Starteam precisam ser migrados.

  4. Anexar aprovação do Gerente de Projeto.

  5. Seguir documentação:
    8.3. Correção dos jars embarcados - ENGENHARIA DE PLATAFORMA | Tribo

Erro Build

1.3 Falha na etapa Publish artifact nexus com erro: Status 400 cannot be updated

🧠 Resposta da BIA TECH – A etapa de build apresentou falha.

Olá! 👋

🔍 O que isso significa?
O erro ocorre pois foi realizado rerun completo da pipeline, gerando conflito ao tentar publicar um artefato já existente no Nexus.

✅ O que você deve fazer:

  1. Não reutilizar o mesmo build com rerun completo.
  2. Iniciar um novo build/deploy.
  3. Garantir que a versão do artefato não esteja duplicada.

🎯 Motivo:
Erro Build

👥 Time responsável:
Desenvolvimento

1.4 Falha na etapa Run Ant Build com erro: javac invalid target release

🧠 Resposta da BIA TECH – A etapa de build apresentou falha.

Olá! 👋

🔍 O que isso significa?
Existe conflito entre as versões de Java configuradas no build.xml e no workflow/pipeline.

✅ O que você deve fazer:

  1. Validar a versão correta de Java utilizada pelo projeto.
  2. Ajustar a versão no build.xml.
  3. Garantir compatibilidade com a versão definida no pipeline.
  4. Executar novo build após ajuste.

Erro Build

1.8 Erro no build — PATH_DIST não está definido ou está vazio

🧠 Resposta da BIA TECH – A etapa de build apresentou falha.

Olá! 👋

🔍 O que isso significa?
A variável PATH_DIST não foi definida ou está sem valor, impedindo a geração correta do artefato.

✅ O que você deve fazer:

  1. Identificar o caminho correto do artefato (JAR).
  2. Solicitar cadastro/ajuste da variável PATH_DIST via ticket.
  3. Garantir que a variável esteja preenchida corretamente no repositório.
  4. Executar novo build após correção.

Erro Build

Desenvolvimento
